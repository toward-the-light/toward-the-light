# toward-the-light.info

Static website presenting the book *Toward the Light! – A Message to Mankind from the Transcendental World* (published by Michael Agerskov, Copenhagen 1920) to English-speaking readers.

## Status

MVP preview: Home, What is it?, Start here (reading path), Jesus theme page, NDE & science theme page, FAQ.

Content drafts live separately in `site-content/` (Markdown). The HTML pages are the source of truth for the published site.

## Hosting

Designed for GitHub Pages (static HTML/CSS, no build step, no JavaScript dependencies).

- Custom domain: `toward-the-light.info` (see `CNAME`)
- `.nojekyll` disables Jekyll processing so all files are served as-is

## Roadmap

1. Convert the book into HTML chapter pages (Ardor's Account 36 questions, speeches, parables, commentary)
2. Remaining theme pages: Reincarnation, God Light & Darkness, Atlantis, the Agerskovs' story
3. Chapter guide + glossary
4. English videos, quote cards, newsletter
